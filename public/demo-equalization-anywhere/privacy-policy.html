EQ Anywhere

Privacy Policy

Last updated: April 10, 2026

EQ Anywhere processes audio locally in the user's browser so the user can apply equalization and effects to the current tab. EQ Anywhere does not collect, store, sell, or transmit audio data, browsing history, page content, form data, or personal information.

What the extension does

EQ Anywhere lets the user apply a 10-band equalizer and a small set of effects, including reverb, delay, chorus, and phaser, to audio in the current tab. All processing happens locally on the user's device using browser APIs.

Data collection

EQ Anywhere does not collect or retain:

  • audio recordings or captured tab audio content
  • browsing history
  • cookies
  • page text or form entries
  • account, location, analytics, or advertising data

No captured audio or user data is sent to remote servers.

Permissions

  • tabs is used to identify and update the active tab during processing.
  • tabCapture is used to access the current tab's audio stream after explicit user action.
  • offscreen is used to run the Web Audio graph in an offscreen document.
  • Host access is used so the extension can operate on the sites where the user chooses to enable it.

Sharing and sale of data

EQ Anywhere does not sell user data and does not share user data with third parties, because it does not collect that data.

Policy updates

If the extension's data practices change, this policy will be updated before the affected release is published.
